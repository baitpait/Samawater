# نظام تسجيل الدخول للموزعين برقم الهاتف

## 📋 نظرة عامة

تم تطوير نظام تسجيل دخول مخصص يسمح للموزعين بتسجيل الدخول برقم الهاتف مباشرة، بينما يسمح للمسؤولين بتسجيل الدخول بالبريد الإلكتروني.

---

## ✅ الميزات المطبقة

### 1. **تسجيل الدخول برقم الهاتف**
   - الموزعون يمكنهم تسجيل الدخول برقم الهاتف مباشرة
   - المسؤولون يستمرون في استخدام البريد الإلكتروني
   - النظام يتحقق تلقائياً من نوع الإدخال

### 2. **إصلاحات الأمان**
   - ✅ استخدام نفس الـ hash لكلمة المرور في `users` و `distributors`
   - ✅ التحقق من صحة كلمة المرور قبل الحفظ
   - ✅ معالجة الأخطاء مع try-catch
   - ✅ حذف الموزع تلقائياً إذا فشل إنشاء المستخدم

### 3. **التحقق والتحقق من الصحة**
   - ✅ التحقق من عدم تكرار email
   - ✅ التحقق من طول كلمة المرور (6 أحرف على الأقل)
   - ✅ التحقق من وجود دور الموزع قبل الإنشاء

## 🛡️ الحماية من الأخطاء

### 1. **حفظ كلمة المرور:**
```php
// ✅ صحيح: استخدام نفس الـ hash
$hashedPassword = bcrypt($request->password_hash);
$distributor->password_hash = $hashedPassword;
$user->password = $hashedPassword; // نفس الـ hash

// ❌ خطأ: تشفير مرتين
$distributor->password_hash = bcrypt($request->password_hash);
$user->password = bcrypt($request->password_hash); // hash مختلف!
```

### 2. **معالجة الأخطاء:**
```php
try {
    // إنشاء الموزع
    $distributor = Distributor::create([...]);
    
    // إنشاء المستخدم
    $user = User::create([...]);
    
} catch (\Exception $e) {
    // حذف الموزع إذا فشل إنشاء المستخدم
    if (isset($distributor) && $distributor->id) {
        $distributor->delete();
    }
    
    \Log::error('خطأ في إنشاء موزع', ['error' => $e->getMessage()]);
}
```

### 3. **التحقق من البيانات:**
```php
// التحقق من كلمة المرور
if (empty($request->password_hash) || strlen($request->password_hash) < 6) {
    \Alert::error('كلمة المرور يجب أن تكون على الأقل 6 أحرف');
    return redirect()->back();
}

// التحقق من عدم تكرار email
if (User::where('email', $email)->exists()) {
    \Alert::error('البريد الإلكتروني مستخدم بالفعل');
    return redirect()->back();
}
```

## 📝 التوصيات

### 1. **عند إضافة موزع جديد:**
- ✅ تأكد من إدخال رقم هاتف صحيح (10-15 رقم)
- ✅ تأكد من إدخال كلمة مرور قوية (6 أحرف على الأقل)
- ✅ تأكد من عدم تكرار رقم الهاتف

### 2. **عند تحديث موزع:**
- ✅ إذا غيرت رقم الهاتف، سيتم تحديث email تلقائياً
- ✅ إذا غيرت كلمة المرور، سيتم تحديثها في كلا الجدولين
- ✅ إذا تركت كلمة المرور فارغة، لن يتم تحديثها

### 3. **عند تسجيل الدخول:**
- ✅ للموزعين: استخدم رقم الهاتف مباشرة
- ✅ للمسؤولين: استخدم البريد الإلكتروني
- ✅ النظام يتحقق تلقائياً من نوع الإدخال

## 🔍 استكشاف الأخطاء

### المشكلة: "كلمة المرور غير صحيحة"
**الحل:**
1. تحقق من أن كلمة المرور في `users.password` و `distributors.password_hash` متطابقة
2. استخدم نفس الـ hash في كلا الجدولين
3. تحقق من أن كلمة المرور لم يتم تشفيرها مرتين

### المشكلة: "البريد الإلكتروني مستخدم بالفعل"
**الحل:**
1. تحقق من عدم وجود مستخدم آخر بنفس رقم الهاتف
2. تحقق من أن email = `phone@distributor.local`
3. إذا كان موجوداً، احذف المستخدم القديم أولاً

### المشكلة: "فشل إنشاء حساب المستخدم"
**الحل:**
1. تحقق من وجود دور "distributor" في قاعدة البيانات
2. تحقق من logs في `storage/logs/laravel.log`
3. تأكد من أن جميع الحقول المطلوبة موجودة
