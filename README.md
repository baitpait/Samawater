# Eliyaa Water Distribution System
نظام توزيع مياه ايلياء - Laravel + Backpack

## المميزات
- إدارة العملاء والموزعين
- تتبع التسليمات والمدفوعات
- التقارير والإحصائيات
- تصميم متجاوب بخط Cairo
- نسخ احتياطي تلقائي

## التثبيت
1. `git clone git@github.com:baiitpait/eliyaa-water-distribution.git`
2. `composer install`
3. `php artisan migrate`

## النشر
`git pull origin main` على السيرفر
